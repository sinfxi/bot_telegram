# FXI Telegram Community Manager

ربات مدیریت جامعهٔ تلگرام و دستیار چندمدلی FXI، همراه با پنل مدیریت فارسی و API مبتنی بر FastAPI.

## امکانات

- پاسخ‌گویی هوشمند متنی و تحلیل تصویر رسید فقط از طریق OpenRouter؛ هیچ ارائه‌دهندهٔ هوش مصنوعی دیگری در نسخه فعلی پیکربندی یا استفاده نمی‌شود.
- تاریخچهٔ مکالمه با PostgreSQL و مدیریت نشست‌های چت.
- پاسخ‌گویی به پیام گروه فقط در صورت خطاب‌کردن ربات یا پاسخ به پیام آن؛ برای جلوگیری از مزاحمت، پاسخ‌گویی گروهی باید با تنظیمات همان گروه فعال باشد.
- کنترل قابلیت‌های اصلی از پنل مدیریت؛ تبدیل گفتار به متن در نسخه OpenRouter-only غیرفعال است.
- فرمان‌های طبیعی فارسی برای روشن/خاموش‌کردن پاسخ هوشمند، مشاهدهٔ آمار، دریافت قوانین و تهیهٔ پیش‌نویس.
- ابزارهای مدیریت جامعه: قوانین، mute/unmute، ban، pin، آمار، گزارش کانال، پست‌های برتر، برنامهٔ محتوا و پیشنهادها.
- پنل مدیریت: وضعیت سرویس، OpenRouter، کاربران و مدیران، تاریخچهٔ مکالمه، بررسی درخواست‌ها، پیام همگانی، دستورالعمل مدل، تنظیم روشن/خاموش قابلیت‌ها، آمار جامعه، گزارش فعالیت‌های مدیریتی و خروجی CSV کاربران.
- گزارش مدیریتی محدود به ۵۰۰ رویداد اخیر؛ جزئیات حساس یا کلیدهای API در گزارش ذخیره نمی‌شوند.
- مسیر `/health` برای بررسی زنده‌بودن سرویس وب (liveness) و `/ready` برای بررسی آمادگی اتصال‌های ضروری (readiness)؛ `/admin/api/*` برای ابزارهای مدیریتی احراز هویت‌شده.

## اجرای محلی

نیازمندی: Python 3.11 یا جدیدتر.

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app:app --app-dir . --host 0.0.0.0 --port 8000
```

مقادیر `.env` را با تنظیمات خودت پر کن. در Windows می‌توانی متغیرها را از طریق تنظیمات Run/PowerShell یا یک ابزار بارگذاری dotenv تنظیم کنی. هیچ‌وقت توکن‌ها یا کلیدهای API را در GitHub ثبت نکن.

## متغیرهای اصلی

| متغیر | کاربرد |
|---|---|
| `ZEUS_BOT_TOKEN` | توکن ربات تلگرام از BotFather |
| `TELEGRAM_BOT_USERNAME` | نام کاربری ربات بدون @؛ برای تشخیص خطاب مستقیم |
| `ADMIN_IDS` | شناسه‌های عددی مدیران اصلی، جداشده با کاما |
| `ADMIN_PANEL_PASSWORD` | رمز مشترک ورود پنل؛ نام کاربری باید آیدی عددی تلگرامِ ثبت‌شده در `ADMIN_IDS` یا فهرست مدیران باشد |
| `ADMIN_PANEL_URL` | آدرس عمومی پایهٔ پنل، بدون `/admin`؛ برای ساخت لینک‌های یک‌بارمصرف ادمین |
| `DATABASE_URL` | اتصال PostgreSQL برای وضعیت و تاریخچهٔ پایدار |
| `ADMIN_DATA_FILE` | مسیر فایل JSON جایگزین؛ در میزبانی ابری فایل موقت ممکن است با راه‌اندازی مجدد از بین برود |
| `AI_SYSTEM_PROMPT` | دستورالعمل اولیهٔ دستیار |
| `OPENROUTER_API_KEY` | کلید دسترسی تنها ارائه‌دهندهٔ هوش مصنوعی در این نسخه |

| `LOG_LEVEL` | سطح لاگ، مانند `INFO` |

برای پاسخ هوشمند و تحلیل تصویر رسید، `OPENROUTER_API_KEY` را تنظیم کن. قابلیت‌های قابل‌تنظیم از صفحهٔ «قابلیت‌های ربات» در پنل مدیریت ذخیره می‌شوند؛ پیام صوتی تا پیاده‌سازی سازگار با OpenRouter غیرفعال است.

## دیپلوی روی Render

Build command:

```bash
pip install -r telegram-delete-assistant-pro/requirements.txt
```

Start command:

```bash
uvicorn app:app --app-dir telegram-delete-assistant-pro --host 0.0.0.0 --port $PORT
```

تنظیمات ضروری را در متغیرهای محیطی (Environment) سرویس Render وارد کن. برای حفظ تاریخچه و وضعیت، PostgreSQL را از طریق `DATABASE_URL` متصل کن. فقط یک نمونهٔ polling برای هر توکن ربات اجرا کن؛ چند نمونهٔ هم‌زمان ممکن است خطای Telegram `getUpdates conflict` ایجاد کنند.

- پنل: `/admin`
- سلامت سرویس وب: `GET /health` پاسخ `200` می‌دهد وقتی فرایند وب پاسخ‌گوست؛ تنظیم نبودن یک ارائه‌دهندهٔ اختیاری هوش مصنوعی نباید Health Check را قرمز کند.
- آمادگی اتصال‌ها: `GET /ready` پاسخ `200` یا `503` می‌دهد و فقط وضعیت کلی تلگرام، هوش مصنوعی و دیتابیس را بدون افشای نام ارائه‌دهنده‌ها برمی‌گرداند.
- مخزن: `sinfxi/bot_telegram`

## فرمان‌های طبیعی و صوتی

در گروه، برای حفظ حریم خصوصی ربات فقط صوتی را پردازش می‌کند که کپشن آن خطاب به ربات باشد یا در پاسخ به پیام ربات ارسال شده باشد. نمونه:
- «ربات، پاسخ هوشمند رو روشن کن»
- «ربات، آمار گروه رو بگو»
- «ربات، قوانین گروه رو بگو»
- «ربات، یه پیش‌نویس درباره امنیت بساز»

فرمان‌های مدیریتی مانند روشن/خاموش‌کردن AI و ساخت پیش‌نویس فقط برای مدیران گروه اجرا می‌شوند. پیش‌نویس به‌صورت خودکار منتشر نمی‌شود.

## نکات امنیتی و محدودیت‌ها

- ورود مستقیم پنل با HTTP Basic انجام می‌شود: نام کاربری آیدی عددی تلگرام و رمز `ADMIN_PANEL_PASSWORD` است. آیدی باید در فهرست مدیران مجاز باشد؛ در غیر این صورت حتی با رمز صحیح پیام «شما ادمین نیستید.» برمی‌گردد. ادمین‌های افزوده‌شده همچنان می‌توانند از لینک دعوت تلگرامی یک‌بارمصرف با اعتبار ۳۰ دقیقه استفاده کنند و نشست پس از ورود ۱۲ ساعت اعتبار دارد.
- ادمین‌های عادی به‌صورت پیش‌فرض فقط نمای کلی را می‌بینند. سطح دسترسی هر ادمین از پنل تعیین می‌شود و مجوزها برای هر درخواست در سمت سرور بررسی می‌شوند؛ حذف ادمین دسترسی API را فوراً لغو می‌کند.
- مقدار `ADMIN_PANEL_URL` را روی آدرس پایهٔ HTTPS سرویس بگذار و `/admin` به انتهای آن اضافه نکن. ادمین باید قبلاً ربات را در تلگرام Start کرده باشد تا بتواند پیام خصوصی دریافت کند.
- مدیر اصلی با HTTP Basic وارد می‌شود؛ رمز طولانی و منحصربه‌فرد تعیین کن و فقط روی HTTPS استفاده کن.
- کلیدهای API در پنل نمایش داده نمی‌شوند و باید از طریق متغیرهای محیطی میزبان مدیریت شوند.
- گزارش فعالیت مدیریتی برای عیب‌یابی و پیگیری تغییرات است؛ جایگزین سامانهٔ حسابرسی سازمانی نیست.
- آمار گروه و کانال از زمان اضافه‌شدن ربات و دریافت رویدادها جمع می‌شود؛ ربات به‌طور خودکار تاریخچهٔ قدیمی تلگرام را بازیابی نمی‌کند.
- برای اجرای قابلیت‌های مدیریتی، ربات باید مجوزهای لازم را در گروه داشته باشد؛ حذف یا محدودکردن اعضا و سنجاق‌کردن پیام نیز به دسترسی مدیریتی مناسب نیاز دارد.
- تنها OpenRouter برای مدل و تحلیل تصویر استفاده می‌شود؛ پیام صوتی در این نسخه غیرفعال است.


## ورود کاربران و مدیر پنل

- صفحهٔ ورود: `/login`
- مدیر با `ADMIN_PANEL_USERNAME` و `ADMIN_PANEL_PASSWORD` وارد پنل `/admin` می‌شود.
- کاربران عادی می‌توانند ثبت‌نام کنند و به صفحهٔ حساب خود در `/account` وارد شوند؛ حساب کاربری عادی مجوز مدیریت ندارد.
- رمز کاربران با PBKDF2-HMAC-SHA256 و salt تصادفی ذخیره می‌شود و نشست‌ها در کوکی HttpOnly نگهداری می‌شوند.
- مقدار تصادفی و طولانی `SESSION_SECRET` را در تنظیمات Environment سرویس قرار بده و آن را در مخزن ثبت نکن.
- برای غیرفعال‌کردن ثبت‌نام عمومی، `PANEL_ALLOW_REGISTRATION=false` تنظیم کن.
- حساب پنل با شناسهٔ تلگرام یکی نیست؛ فقط کاربرانی که ربات را در تلگرام Start کرده‌اند در فهرست گیرندگان پیام همگانی قرار می‌گیرند.
