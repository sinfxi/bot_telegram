کنترل انتشار و بازیابی سرویس

Render

اگر سرویس متوقف شده یا نسخه جدید لازم است، صفحه انتشار Render را باز کن و از Manual Deploy استفاده کن. لینک زیر فقط داشبورد را باز می‌کند؛ هیچ توکن یا کلید محرمانه‌ای در مرورگر قرار نمی‌گیرد.

🚀 باز کردن پنل Deploy در Render🩺 بررسی Health API

برای فعال‌شدن ناظر خودکار هر ۱۰ دقیقه، طبق فایل MONITORING_FA.md یک Cron Job جدا بساز و متغیرهای لازم را فقط در تنظیمات امن Render قرار بده.

تنظیمات و نکات عملیاتی

توکن تلگرامZEUS_BOT_TOKEN — فقط در Environment
مدیر اعلان‌هاADMIN_CHAT_ID — شناسه عددی اکانت مدیر برای گزارش‌های ناظر
کلید بازیابیRENDER_DEPLOY_HOOK_URL — آدرس محرمانه Deploy Hook؛ هرگز در کد یا چت عمومی منتشر نکن
پایش سلامتهر ۱۰ دقیقه؛ بررسی HTTP و پاسخ getMe تلگرام

مانیتور فقط می‌تواند وقتی برنامه از دسترس خارج است از طریق Deploy Hook تلاش به راه‌اندازی مجدد کند. اگر خود Render یا توکن/سرویس خراب باشد، تضمین آنلاین‌شدن وجود ندارد. اعلان آنلاین‌بودن هر ۱۰ دقیقه ممکن است پیام‌های زیادی تولید کند.
