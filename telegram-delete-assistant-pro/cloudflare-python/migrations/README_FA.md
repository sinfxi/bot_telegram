# راهنمای مهاجرت دیتابیس آزمایشی

- `0001_initial.sql`: ساخت جدول‌های اولیهٔ updateها، تاریخچهٔ پیام و پست‌های کانال.
- `0002_update_claim_lease.sql`: افزودن `claimed_at` برای بازیابی updateهایی که پردازش آن‌ها با قطع Worker نیمه‌تمام مانده است.

ترتیب اجرا برای دیتابیس تازه: فقط `0001_initial.sql`؛ چون ستون `claimed_at` در نسخهٔ اولیه وجود دارد.
برای دیتابیس staging ساخته‌شده پیش از این تغییر: `0002_update_claim_lease.sql` را یک بار اجرا کنید.

این migrationها فقط مربوط به دیتابیس `fxi-telegram-assistant-stage` هستند و نباید روی دیتابیس production اجرا شوند.
