# راهنمای تنظیم OpenRouter برای FXI

در نسخه فعلی FXI فقط **OpenRouter** به‌عنوان ارائه‌دهنده هوش مصنوعی پیکربندی شده است. متغیرهای قدیمی Gemini، Groq، Mistral، Cloudflare AI، NVIDIA، SambaNova و Cohere در این نسخه استفاده نمی‌شوند؛ برای آن‌ها کلید تنظیم نکن.

## متغیرهای محیطی

| متغیر | ضروری | کاربرد |
|---|---|---|
| `OPENROUTER_API_KEY` | برای قابلیت‌های AI بله | کلید دسترسی OpenRouter |
| `OPENROUTER_MODEL` | اختیاری | شناسه مدل؛ پیش‌فرض کد `openrouter/free` |
| `AI_SYSTEM_PROMPT` | اختیاری | دستورالعمل پایه شخصیت و رفتار FXI |
| `ZEUS_BOT_TOKEN` | برای اجرای ربات بله | توکن BotFather |

کلید واقعی را فقط در Environment سرویس Render وارد کن. هرگز آن را در GitHub، کد، فایل عمومی یا پیام تلگرام قرار نده. اگر کلیدی منتشر شد، آن را از OpenRouter باطل و دوباره صادر کن.

## تنظیم در Render

1. سرویس FXI را در Render باز کن.
2. وارد بخش Environment شو.
3. `OPENROUTER_API_KEY` را اضافه کن.
4. در صورت نیاز `OPENROUTER_MODEL` را با یک شناسه مدل قابل‌استفاده در حساب خودت تنظیم کن.
5. سرویس را Deploy مجدد کن و لاگ startup را بررسی کن.

مدل `openrouter/free` تضمین دسترسی دائمی یا ظرفیت نامحدود نیست؛ فهرست مدل‌های رایگان، محدودیت نرخ و سهمیه ممکن است تغییر کند.

## عیب‌یابی

- **کلید تنظیم نشده:** ربات پیام می‌دهد که OpenRouter فعال نیست.
- **401 یا 403:** کلید یا دسترسی نامعتبر است؛ کلید را در Render بررسی و در صورت لزوم تعویض کن.
- **404 یا model not found:** شناسه مدل در دسترس نیست؛ مدل معتبر دیگری انتخاب کن.
- **429:** محدودیت نرخ یا سهمیه فعال شده؛ بعداً دوباره تلاش کن یا محدودیت حساب را بررسی کن.
- **5xx:** سرویس بالادستی موقتاً دچار مشکل است؛ لاگ و وضعیت OpenRouter را بررسی کن.

نمایش «configured» در پنل فقط وجود کلید در Environment را نشان می‌دهد و اعتبار کلید، موجودی یا پاسخ‌گویی مدل را تضمین نمی‌کند.

## حریم خصوصی

پیام کاربر و زمینه مکالمه‌ای که برای پاسخ لازم است ممکن است به API OpenRouter ارسال شود. در گروه‌ها حالت پیش‌فرض پاسخ‌گویی محدود به منشن یا Reply است؛ حالت گفت‌وگوی رفاقتی می‌تواند پیام‌های بیشتری را برای پردازش انتخاب کند. پیش از فعال‌سازی، اعضا را از این موضوع مطلع کن و اطلاعات محرمانه ارسال نکن.
