# Commands

## 👑 Global admin
- `/admin` — admin panel
- `/broadcast` — broadcast a message
- `/cancel` — cancel broadcast mode

## 🛡 Moderation
- `/ban` `/unban`
- `/mute` `/unmute`
- `/warn` `/warnings` `/clearwarn`
- `/promote` `/demote`
- `/del` `/pin`

## 🔐 Security
- `/antilink on|off`
- `/antispam on|off`
- `/captcha on|off`
- `/filter <word>`
- `/unfilter <word>`
- `/filters`

## 👋 Community
- `/welcome on|off`
- `/rules`

## 📝 Notes
- `/note <name> <text>`
- `/getnote <name>`
- `/notes`
- `/id`

> Commands that change group settings require group-admin permissions.
