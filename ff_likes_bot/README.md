# IranFF Request Bot

ربات تلگرامی ثبت و مدیریت درخواست‌های Free Fire.

## امکانات
- ثبت درخواست با UID و Region
- مشاهده درخواست‌های اخیر و وضعیت آن‌ها
- پنل مدیریت محدود به شناسه ادمین
- آمار کاربران و درخواست‌ها
- تأیید یا رد درخواست و اطلاع‌رسانی به کاربر
- ذخیره‌سازی SQLite

## استقرار روی Railway
در تنظیمات سرویس، Root Directory را روی `ff_likes_bot` قرار بده و متغیرهای زیر را بساز:
- `BOT_TOKEN`: توکن تازه از BotFather؛ آن را در GitHub یا چت نگذار.
- `ADMIN_ID`: شناسه ادمین، پیش‌فرض `6384557276`.

دستور اجرا: `python main.py`

## مهم
این نسخه درخواست‌ها را ثبت و مدیریت می‌کند. اجرای واقعی لایک به API معتبر و مجاز نیاز دارد؛ بدون اتصال آن، ربات ادعای انجام خودکار لایک نمی‌کند.
