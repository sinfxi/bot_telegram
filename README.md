# 🤖 ربات تلگرام همه‌کاره

> یک ربات برای مدیریت گروه، ابزارهای روزمره و چند مدل هوش مصنوعی؛ بدون اینکه برای هر کار یک ربات جدا لازم باشد.

این پروژه را با یک ایده شروع کردم: کارهای معمول مدیریت گروه باید ساده‌تر باشند. برای همین مدیریت اعضا، امنیت، یادداشت‌ها، پنل مدیریتی و هوش مصنوعی را کنار هم آوردم.

## قابلیت‌های اصلی

| بخش | قابلیت‌ها |
|---|---|
| 👥 مدیریت اعضا | بن، آن‌بن، اخراج، میوت، اخطار و مدیریت دسترسی ادمین |
| 🛡️ امنیت گروه | ضدلینک، ضداسپم، CAPTCHA، فیلتر کلمات و قفل گروه |
| 👋 تنظیمات گروه | خوشامدگویی و قوانین |
| 📝 ابزارها | Notes، گزارش، آمار و پیام همگانی |
| 🎛️ پنل | پنل مدیریتی تعاملی |
| 💬 AI Chat | گفت‌وگوی فارسی با لحن‌های مختلف |
| 🧠 AI Answer | حالت جداگانه برای پاسخ مستقیم به سؤال‌ها |
| 👑 AI Commander | تشخیص عبارت‌های مدیریتی طبیعی، با بررسی ادمین و تأیید عملیات حساس |
| ⭐ VIP | ثبت کاربر ویژه، مدت اعتبار، اطلاعات سطح دسترسی و گزارش کاربران ویژه |

## سه حالت هوش مصنوعی

- **AI Chat:** گفت‌وگوی دوستانه؛ در گروه با Reply به ربات یا اشاره به آن.
- **AI Answer:** پاسخ متمرکز به سؤال‌ها با دستور `/question` یا `/ask` و عبارت‌های طبیعی مثل «سوال ...».
- **AI Commander:** دستیار جداگانه برای فهم درخواست‌های مدیریتی. برای کاربر هدف روی پیام او Reply کن؛ برای تغییر VIP هم جزئیات پیش از اجرا نمایش داده می‌شود و ادمین باید تأیید کند.

نمونه‌ها:

```text
/ask پایتون چیست؟
/question چرا آسمان آبی است؟

# روی پیام یک کاربر Reply کن:
این کاربر رو ۷ روز ویژه کن
این کاربر رو بن کن
به این کاربر اخطار بده

# برای گزارش:
گزارش کاربران ویژه
```

عملیات مدیریتی تنها در صورت داشتن مجوز لازم ادمین و دسترسی ربات اجرا می‌شوند. تشخیص هوش مصنوعی به‌تنهایی مجوز اجرای عملیات نیست.

## VIP چه چیزهایی نگه می‌دارد؟

- افزودن یا حذف VIP با Reply
- اعتبار نامحدود یا ۱ تا ۳۶۵ روز
- ثبت توضیح سطح دسترسی برای کاربر
- گزارش کاربران ویژه و زمان باقی‌مانده

**توجه:** سطح دسترسی فعلاً به‌صورت داده ذخیره می‌شود؛ محدودکردن خودکار قابلیت‌های دیگر ربات بر اساس هر سطح، هنوز نیازمند تعریف و اتصال سیاست‌های مجوزدهی مشخص است.

## تنظیمات محیطی

این متغیرها را در تنظیمات امن سرویس اجرا (مثلاً Railway) قرار بده؛ کلیدها را داخل کد یا GitHub commit نکن.

| متغیر | کاربرد |
|---|---|
| `BOT_TOKEN` | توکن ربات تلگرام |
| `ADMIN_IDS` | شناسه مدیران اصلی |
| `OPENAI_API_KEY` | کلید پیش‌فرض AI Chat |
| `OPENAI_MODEL` | مدل AI Chat |
| `QNA_OPENAI_API_KEY` | کلید جدا برای AI Answer؛ در صورت خالی بودن از کلید پیش‌فرض استفاده می‌کند |
| `QNA_MODEL` | مدل AI Answer |
| `ADMIN_AI_API_KEY` | کلید جدا برای AI Commander؛ در صورت خالی بودن از کلید پیش‌فرض استفاده می‌کند |
| `ADMIN_AI_MODEL` | مدل AI Commander |
| `DB_PATH` | مسیر دیتابیس SQLite |
| `PORT` | پورت سرویس سلامت |

نمونه نام متغیرها در [.env.example](.env.example) آمده است.
