## 👀 یک سناریوی واقعی

فرض کن یک نفر تازه وارد گروه شده.

CAPTCHA روشن است؛ پس قبل از اینکه شروع کند به فرستادن پیام، باید خودش را تأیید کند.

حالا یک نفر لینک تبلیغاتی می‌فرستد:

```
🔗 پیام شناسایی شد
        ↓
🛡️ Anti-Link
        ↓
🗑️ حذف پیام
```

یکی هم شروع می‌کند پشت سر هم پیام فرستادن:

```
⚡ رفتار مشکوک
        ↓
🛡️ Anti-Spam
        ↓
🚨 واکنش ربات
```

و اگر کسی قوانین گروه را جدی نگیرد:

```
⚠️ اخطار اول
      ↓
⚠️ اخطار دوم
      ↓
🚨 اخطار سوم
      ↓
🔒 محدودسازی
```

در طرف دیگر، ادمین همه این‌ها را کنترل می‌کند.

**ایده اصلی پروژه همین است: یک ربات، چندین ابزار مدیریتی.**

## 👑 پنل مدیریت

یکی از قسمت‌هایی که برای این پروژه مهم بود، این بود که همه‌چیز فقط به چند دستور متنی محدود نشود.

طرح کلی پنل:

```
┌─────────────────────────────────┐
│          👑 ADMIN PANEL         │
├─────────────────────────────────┤
│  📊 آمار          👥 کاربران    │
│                                 │
│  🛡 امنیت         📝 امکانات    │
│                                 │
│             📢 همگانی           │
└─────────────────────────────────┘
```

از همین پنل می‌شود به بخش‌های مختلف مدیریتی دسترسی داشت.

# 🧠 سیستم Warning

Warning فقط یک عدد نیست.

برای هر گروه و کاربر جداگانه نگهداری می‌شود و بعد از رسیدن به حد مشخص، ربات می‌تواند محدودسازی را انجام دهد.

مثلاً:

```
User
 │
 ├── ⚠️ 1
 │
 ├── ⚠️ 2
 │
 └── 🚨 3
       │
       └── 🔒 Restrict
```

این بخش با SQLite ذخیره می‌شود تا وضعیت اخطارها بین اجرای برنامه باقی بماند.

# 🛡️ امنیت گروه

### 🔗 Anti-Link

وقتی فعال باشد، لینک‌های مشخص‌شده در پیام‌ها شناسایی می‌شوند و ربات می‌تواند پیام را حذف کند.

### ⚡ Anti-Spam

ارسال سریع و پشت‌سرهم پیام‌ها را بررسی می‌کند و برای رفتارهای اسپمی واکنش نشان می‌دهد.

### 🤖 CAPTCHA

برای اعضای جدید می‌توان CAPTCHA ورود را فعال کرد.

### 🚫 Word Filter

کلمات موردنظر ادمین را تعریف کن و ربات آن‌ها را در پیام‌ها بررسی می‌کند.

# 📝 Notes؛ کوچک ولی کاربردی

فرض کن قوانین گروه را بارها باید برای کاربران بفرستی.

یک بار ذخیره‌اش کن:

```
/note rules قوانین کامل گروه...
```

بعد هر وقت لازم شد:

```
/getnote rules
```

تمام.

برای قوانین، FAQ، پاسخ‌های آماده و پیام‌های پرتکرار خیلی به درد می‌خورد.

# 🚀 راه‌اندازی

### 1. نصب

```bash
pip install -r requirements.txt
```

### 2. تنظیم متغیرها

```env
BOT_TOKEN=your_bot_token
ADMIN_IDS=123456789
DB_PATH=bot.db
PORT=8080
```

### 3. اجرا

```bash
python bot.py
```

> 🔒 توکن ربات را داخل GitHub قرار نده. از Environment Variables استفاده کن.
